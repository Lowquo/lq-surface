# lq-surface v0.1.0 (draft)

> **Draft, not released.** Prepared on 2026-11-20. Nothing has been tagged or published. Publishing needs
> the maintainer's explicit approval ([release procedure](https://github.com/Lowquo/lq-surface/blob/main/docs/releasing.md#7-npm-publication-only-with-explicit-approval)).
> All links are absolute so this text can be pasted into a GitHub release as it is.

This is the first npm release of lq-surface: precise, accessible three-axis controls for audio software
interfaces, kept independent of any DSP. The framework packages are MIT-licensed and contain no JUCE code.

## Packages

| Package | What it is |
| --- | --- |
| [`@lowquo/surface`](https://github.com/Lowquo/lq-surface/tree/main/packages/core) | Pure TypeScript pose, parameter and sound-region maths, plus the host-bridge contract. No DOM, Three.js or JUCE, and no runtime dependencies. |
| [`@lowquo/surface-controls`](https://github.com/Lowquo/lq-surface/tree/main/packages/controls) | The trackball. Three.js rendering with a real 2D-canvas fallback, keyboard and screen-reader support, balanced and coalesced gestures, and no rendering while idle. Peer dependency: `three` `^0.187.0`. |
| [`@lowquo/surface-juce`](https://github.com/Lowquo/lq-surface/tree/main/packages/juce) | Adapter for JUCE `WebBrowserComponent` native functions, which the page injects (the package contains no JUCE code). Gesture-balanced, deduplicated and coalesced host writes, validated host state, and `SurfaceHostSession`. |

```sh
npm install @lowquo/surface @lowquo/surface-controls three
npm install @lowquo/surface-juce   # only for JUCE WebView hosts
```

The packages are ES modules with TypeScript declarations, and work with `moduleResolution` `bundler` and
`nodenext`. `@lowquo/surface-controls` needs the `DOM` lib.

## Highlights

- **A precise contract.** x and y lie in [-1, 1] on the unit disk, and x² + y² ≤ 1 holds exactly in IEEE-754
  doubles (points outside are projected radially). z lies in [0, 1], and neutral is { 0, 0, 0.5 }. The host
  parameters `surface_x`, `surface_y` and `surface_z` are normalised to [0, 1].
- **The host is authoritative.** The UI writes only inside balanced begin/set/end gestures, and host updates
  are never echoed back. After a gesture, `SurfaceHostSession` re-reads the host's state so the UI converges
  to it.
- **Studio precision.** The marker's screen position is the value. Shift, Ctrl or Cmd gives 10× finer
  steps. Keyboard steps are 1 % of the range, Escape cancels a drag, and nothing animates.
- **Accessibility.** Full keyboard control, a role description, instructions, and a debounced live value. Manual
  screen-reader verification is still pending.
- **Examples, source only:** the browser playground, and a JUCE 9 example plug-in (VST3, plus AU on macOS)
  with a frozen identity (`Lqoo` / `Lqsf` / `io.lowquo.surface.example`). The example is built and validated
  in CI but **not distributed as binaries**.

## Verification

- GitHub Actions on ubuntu, macOS and windows run: `npm ci` from the committed lockfile, typecheck,
  build, 103 unit tests, `check:pack` (tarball contents, a consumer install from the tarballs, Node import, and
  TypeScript `bundler` and `nodenext`), a publish dry run, and 33 Chromium browser tests.
- JUCE example: builds on macOS (AU + VST3) and Windows (VST3 + WebView2), passes a headless native suite,
  and passes a WKWebView smoke test. **pluginval v1.0.4 at strictness 10** passes for the macOS VST3 and AU and
  the Windows VST3, and **`auval -strict`** passes.
- **Not yet verified:** testing in a DAW, VoiceOver and NVDA, Steinberg's VST3 validator, and what the WebView2
  page displays on Windows. See [docs/testing.md](https://github.com/Lowquo/lq-surface/blob/main/docs/testing.md#status).

## Known limitations

- Host state in the JUCE example is polled at 30 Hz.
- If the WebView content process crashes outright, open gestures stay open until the page reloads or the
  editor closes.
- The example doesn't request editor keyboard focus. Some DAWs may keep the arrow keys for themselves
  (untested).
- 0.x releases may contain breaking changes in minor versions.
